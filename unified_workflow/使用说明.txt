# v1.2 统一漫画工作台

一个 JSON、一个工作台，同时容纳故事、可选分镜图、可选参考图。无需切换之前四个工作流。

| 输入 | 自动处理 |
| --- | --- |
| 两张图都不传 | 根据故事自动策划分镜，生成漫画页 |
| 只传参考图 | 保留参考图人物与构图，转绘为单幅漫画 |
| 上传分镜图 | 上传后自动检查编号区域；确认后逐格生成、原位合成 |
| 分镜图与参考图都上传 | 分镜决定区域与镜头，参考图辅助人物外观与服装；仍需先确认分镜 |

## 安装

1. 本包建立在 v1.0/v1.1 的 ComfyUI 0.43.0 / MOSS 环境上。保留原四模型；参考图与分镜重绘需增加此前约 297MB 的 MOSS Edit LoRA，见 `edit_model.json`。无图自动分镜不会加载这份 LoRA。
2. 关闭你的便携版服务，运行 `安装参考图增强包.bat`，填写便携版根目录。本版同时更新 Reference 后端节点和 Launcher 前端；只复制 JSON 不够。已有同名节点会先备份。
3. 若未装编辑 LoRA，运行 `下载图片编辑模型.bat`。已有且哈希一致则跳过。
4. 重启 ComfyUI，浏览器按 Ctrl+F5 刷新。顶部只显示一个“漫画工作台”按钮，点开即可；也可拖入 `00_漫画工作台_自动判断_可选上传.json`。

## 在同一个工作台中使用

### 不上传图片

在故事框写人物、场景、动作、情绪与结尾，点“生成漫画（自动判断）”。分镜图、参考图都可以真正留空，不用上传占位图。自动模式复用原本的主视觉破框/斜切/叠框导演，可在 composition 中选择。

### 上传参考图

在“上传参考图（可选）”选择文件，填写转绘要求，再点“生成漫画”。不上传分镜时，该模式保留原图构图进行单幅漫画化；它不保证在新的多格剧情中自动复用同一张脸。

### 上传分镜图

选择分镜后，系统自动运行一次轻量检查，右侧显示编号预览，暂不加载绘图模型。核对格框与区域：

1. 正确：点击“确认格框并生成”。
2. 不正确：在 panels_json 中修正矩形或多边形坐标，然后点击“检查 / 重新检查分镜框”。
3. 检查通过后，再确认并生成。没有确认过、或确认信息与当前图片/坐标不一致时，后端只重新检查，不会越过确认去绘图。

两张图可以同时上传。参考图用于辅助外观；分镜原图的镜头、区域与布局优先。添加/移除参考图不会改变已检查的格框，换分镜图、修改坐标或边框内缩值则需要重新检查。

点“移除”即可清空某一张图。两张都移除后会回到无图自动分镜，仍使用同一个工作台，不用换标签页。

## 参数

- story：生成故事或转绘要求。参考图模式不要同时要求“大幅换姿势”和“完全保持原图”。
- width / height：无图自动分镜的尺寸。分镜模式保持原分镜页尺寸，参考图模式按参考图比例缩放。
- steps：各模式采样步数，默认 30。
- reference_max_side：参考图片长边，默认 768；8GB 建议先试 512。
- panel_max_side：每格生成长边，默认 512；检查预览不改变原页尺寸。
- border_inset：框内保留带，默认 4 像素；粗框可增加。修改后会要求重新检查。
- reference_denoise：参考图重绘强度，默认 0.65；低一些更接近原图，高一些风格变化更大。
- panel_denoise：分镜逐格重绘强度，默认 0.4。

每格按顺序单独采样，分镜越多耗时越长。没有选择的分支不会加载它的大模型；检查阶段不加载绘图模型。不要通过提高 batch 来批量处理多页，建议用队列。

## 修正格框

自动检测优先识别闭合四边框，复杂叠框、开口边框、背景窗户和对话框可能误判。请以编号预览为准。坐标从原图左上角起算，使用像素 xy，不能直接贴 MOSS 的中心坐标 yxyx。

```json
{
  "width": 768,
  "height": 1152,
  "panels": [
    {"rect":[24,24,743,720],"prompt":"A close-up of the same woman, sad expression."},
    {"polygon":[[24,752],[743,800],[743,1127],[24,1080]],"prompt":"A close-up of her hand holding a watch."}
  ]
}
```

坐标数组顺序决定叠放顺序；背景大格放前，小插入格放后。只有声明过的边界会被合成保护，未声明的气泡、文字或细线仍可能重绘。

## 效果边界

合成可保护确认区域外的原图像素、原页尺寸以及已声明格框的保留带。自动检测本身不保证正确；格内人物、动作、对白和参考图身份也不能承诺百分百匹配。两图同时输入是参考条件，不能视为严格的人脸身份锁定。请先以小图验证效果，再提高尺寸。
